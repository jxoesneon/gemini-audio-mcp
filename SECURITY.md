# Security Policy

## Supported Versions

We only support the latest version of Gemini Audio MCP. Please ensure you are running the most recent release to receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please do not open a public issue. Instead, report it privately to the maintainers.

We will acknowledge your report within 48 hours and provide a timeline for resolution. Once a fix is verified, we will coordinate a public disclosure.

## API Key Security

**Warning**: This project requires a `GEMINI_API_KEY`. 
- Never commit your API key to version control.
- Use environment variables to manage sensitive credentials.
- Rotate your keys immediately if you suspect they have been compromised.
